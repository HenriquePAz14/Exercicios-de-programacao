Esses são exercícios de programação em python que realizei com o intuito de aprimorar minhas habilidades de programação:  

    
exercicio2.py: verifica se um número pertence a sequencia de Fibonacci.  
  
exercicio3.py: lê o arquivo exercicio3.json com valores de faturamento e retorna o maior e o menor faturamento além de calcular a média entre todos eles.  
  
exercicio4.py: declara a variável participação para os estados brasileiros e retorna a porcentagem de cada um deles.  
  
exercicio5.py: recebe uma palavra e a inverte usando uma operação com string.
